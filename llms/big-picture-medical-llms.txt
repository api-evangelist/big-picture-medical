# Big Picture Medical

> Big Picture Medical Limited (London, UK) builds a semantic execution and orchestration
> layer for healthcare data. Its BPM Platform is a low-code/no-code toolset built on
> openEHR specifications that harmonises clinical data across existing systems, holds it
> with lineage and provenance, and turns algorithm, agent and clinician recommendations
> into governed, auditable actions in connected systems. It is deployed in the NHS.

Generated by API Evangelist on 2026-09-02 from the company's public surface. Big Picture
Medical does not publish an llms.txt of its own (https://www.bigpicturemedical.com/llms.txt
returns 404).

## What you should know before trying to integrate

- **There is no public API contract.** No OpenAPI, AsyncAPI, GraphQL SDL, WSDL or .proto is
  published at any URL we could find. The company confirms a REST API exists but supplies
  its documentation as a PDF to contracted customers only.
- **There is no public developer portal.** /developers, /docs, /api, /api-docs and
  /developer-portal all return 404 on www.bigpicturemedical.com.
- **api.bigpicturemedical.com resolves but does not answer.** It has a public A record
  (169.50.196.147, IBM Cloud) and every TCP connection to ports 80, 443, 8080 and 8443
  timed out. It is firewalled to customers.
- **docs.bigpicturemedical.com is a Google Workspace alias.** It redirects to a Google
  account sign-in scoped to bigpicturemedical.com — internal documents, not developer docs.
- **No MCP server, no agent card, no SDK, no webhooks, no status page, no changelog.**
- Getting access means a sales conversation: sales@bigpicturemedical.com. The G-Cloud
  listing contact is Alan Bonfield, alan@bigpicturemedical.com.

## Code

- [GitHub org: big-picture-medical](https://github.com/big-picture-medical) — 8 public
  repositories, none of them a product. Five are hiring exercises; three are forks:
  [ehrbase-fork](https://github.com/big-picture-medical/ehrbase-fork) (of ehrbase/ehrbase,
  an open-source openEHR clinical data repository),
  [cabolabs-ehrserver](https://github.com/big-picture-medical/cabolabs-ehrserver) and
  aws-google-auth. The EHRbase fork corroborates the openEHR claim; its contract belongs
  to the EHRbase project, not to Big Picture Medical.
- npm scope [@bigpicturemedical](https://www.npmjs.com/search?q=%40bigpicturemedical) — four
  packages, all dormant: eslint-config (0.6.0, 2024-02-06), cast (2.1.1, 2021-12-01),
  medkit-vue3 (0.0.1, 2021-12-01), medkit-tokens (0.7.0, 2021-05-10). MedKit is the
  internal design system. None is an API client library.

## Standards and compliance

- openEHR (platform data model), HL7 FHIR and HL7 v2 (interoperability surface) — all
  claimed by the company, none verifiable against a contract.
- ISO/IEC 27001, UKAS-accredited, 2022-07-05. Cyber Essentials. HIPAA Seal of Compliance.
  GDPR / UK Data Protection Act 2018. WCAG 2.1 AA. Connected to the NHS Network (N3).
- Not certified: PCI DSS, CSA STAR. No SOC 2 claim found.
